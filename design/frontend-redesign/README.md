# 纹样工作台 · 新版视觉原型「宣纸 · 黛青」

这里是前端重设计的**静态视觉原型**，仅供评审，不是生产代码：

- 没有接入 `/api/v1`，不发请求；页面数据全是写死的演示数据。
- 不改 `frontend/next-v2/` 里的任何文件；样例图直接引用 `frontend/next-v2/assets/demo/`。
- 没有构建步骤和第三方依赖，字体沿用本机已安装的 Noto Serif SC / Noto Sans SC / Bahnschrift / Cascadia Code。

## 打开

浏览器直接打开 `design/frontend-redesign/index.html`（`file://` 即可，不需要启动服务）。

| 地址 | 内容 |
| --- | --- |
| `index.html#/home` | 概览：首屏原图 / 线稿对比、接着上次、八道工序长卷、最近成果、任务动态、云端用量 |
| `index.html#/workbench` | 工作台：顶部八道工序条 + 左侧版本胶片 + 中间画布 + 右侧本工序参数 |
| `index.html#/library` | 纹样库：统计条、筛选、卡片（悬停切换线稿）、档案抽屉 |
| `index.html#/tasks` | 任务：状态页签、进度、失败原因 |
| `index.html#/settings` | 设置：云端服务、云端调用、本机处理、外观 |

截图或对照时可以加查询参数：`?theme=ink`（深色「夜墨」）、`?stage=1…8`（工作台工序）、`?compare=1`（打开对比），
例如 `index.html?stage=7&compare=1#/workbench`。

## 可交互的部分（只改前端状态）

- 工作台：点工序条或按 `1`–`8` 切工序；`C` 开关对比，拖动分割线；缩放；候选层勾选；提取方式、修复方式、画笔、平铺规格切换；
  滑块实时显示数值；主按钮会模拟一次执行进度，完成后写入一个演示版本并进入下一道工序；云端工序需先勾选价格确认。
- 概览 / 纹样库 / 档案抽屉里的对比滑杆可拖动；纹样库可搜索、筛选；左下角按钮切换「宣纸 / 夜墨」。
- 上传、添加纹样、换纹样、下载等只弹提示。

## 设计要点

- **配色**：浅色生宣底 + 黛青墨（主操作 / 当前）+ 朱砂印（只用于品牌印与 A 级章）；通过用铜绿，待办 / 云端用赭黄，错误用砖红。
  深色「夜墨」只替换令牌，版式不变。令牌集中在 `styles.css` 顶部。
- **图版**：纹样一律放在带纸纹的图版上，画布井用浅点阵与界面分开。
- **工作台**：工序从左侧竖栏改为顶部横向工序条，把横向空间留给画布；版本按工序分组放在左侧；
  右侧参数按「标题 → 分区 → 底部主操作」固定结构，云端工序底部固定显示价格确认。
- 字号地板 12px，正文 14px；中文界面；`prefers-reduced-motion` 下关闭动效。
