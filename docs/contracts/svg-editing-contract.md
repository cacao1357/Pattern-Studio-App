# 系统图形编辑与结果核验契约

日期：2026-11-16。范围：系统功能，沿用现有模型与矢量生成算法，不训练或更换权重。

## SVG 元素编辑

- `GET /api/v1/assets/{asset_id}/svg-elements` 返回 `{asset_id, source_sha256, version, width, height, elements}`。
- 每个元素为 `{id, d, fill, fill_rule, transform, bbox}`；bbox 为画布坐标 `[left, top, right, bottom]`，transform 为已有累计平移 `translate(x,y)`。前端可用受控 DOM 属性构建 SVG，不插入未经检查的原始 SVG。
- 单个 path 中视觉不相连的填色区域独立选择；孔洞与所属区域、同一连通区域的像素矩形子路径共同移动。不同原始 path 保留各自填色与堆叠顺序。此粒度不推断花鸟等语义对象。
- 绘制与导出时，同一原始 path（元素 id 的 p 前缀）且平移相同的元素合并成一次填色绘制，避免分开绘制造成亚像素边缘抗锯齿叠加差异；交互命中区域仍按元素独立。不同原始 path 不合并。
- 曲线采样仅用于判定连接与孔洞归属；保存保留原有曲线路径，不重新描图。过于复杂或无法安全拆分的路径明确报错，不退化为整 path 操作。例如 evenodd 相交子路径形成多个区域且无法在保留原曲线的前提下拆开时，明确拒绝编辑。
- `POST /api/v1/jobs/edit-svg` 使用现有写标记、幂等键及任务轮询。请求为 `{input_asset_id, source_sha256, edits:[{element_id, dx, dy, deleted}]}`；dx/dy 为相对该输入元素的累计像素平移，deleted 默认 false；仅发送实际变化元素。不能传任意 SVG 或路径内容。
- 保存发布新 SVG 资产，原文件不变；保留 image_id、来源、许可、生成修复标记，追加 svg_edit_source 父关系与编辑操作。历史、按图分组、ZIP 导出复用现有系统。
- 编辑不扩展画布，移出 viewBox 的部分在预览及导出中同样裁切；位移仍保留在草稿和保存路径中，可撤销或重置。
- 编辑草稿按当前 SVG 隔离，支持撤销/重做。未保存切换或离开时需明确处理；保存成功后切到新版本，刷新后从已保存版本恢复。禁止静默丢弃未保存草稿。
- 有界操作：单次最多 2000 个元素变化；复杂度超过上限返回 `SVG_EDIT_COMPLEXITY`；未知 ID 返回 `SVG_ELEMENT_NOT_FOUND`；输入指纹不匹配返回 `SVG_EDIT_SOURCE_MISMATCH`。前端显示可理解的错误，不自动删结构或降质。

## 核验与修复引导

- 工作台保留滑动对照，增加透明叠加；两种对照共用同一缩放与坐标。优先核对当前结果与直接同坐标的光栅来源，裁切或旋转后不能简单铺满原图冒充对齐。
- 本地修复的目标尺寸为 512×512。工作台优先使用同一纹样的规范输入作参考图，有多个可用来源时可改选。提交时写入实际使用的参考图 ID，历史记录保留原选择。
- 提示轮廓模式对微小结构的限制，不修改提取或矢量算法。
